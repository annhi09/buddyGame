# BuddyGame Roadmap

## Current Phase
Goal:
Stabilize the core game experience and clean up the product structure.

### Immediate priorities
- Build project brain and workflow docs
- Clean up UI direction for index.html and creator page
- Improve lesson import/export structure
- Fix core multiplayer fairness/sync bugs
- Fix image hydration issues in word-based modes

## Near-Term Roadmap

### 1. Words Game Stability
- stabilize Smash image loading
- stabilize Spell/Type Spell validation rules
- improve warrior single-player vs multiplayer behavior
- ensure round resolution is fair in VS mode

### 2. Creator Tool Upgrade
- redesign creator page into card-based layout
- replace messy inline editing with modal workflows
- support lesson create/edit/delete clearly
- improve import/export usability

### 3. Reading Game Upgrade
- improve repeat sentence features
- fix next-button reliability
- add daily speaking challenge improvements
- make reading mode more game-like and rewarding

### 4. Import / Export
- support reliable JSON export/import
- preserve image data correctly
- prepare future ZIP + manifest structure
- allow teacher/parent sharing workflows

## Mid-Term Roadmap

### 5. Multiplayer Expansion

- improve room setup UX
- improve scoreboard and team feedback

### 6. Content System
- create cleaner lesson metadata
- support age, difficulty, tags, and category fields

### 7. Product Polish
- improve homepage presentation
- improve progression/reward clarity
- strengthen brand feel for Athena & Aria Studio
- create a more cohesive visual system
